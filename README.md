# Little Lemon Restaurant App

Little Lemon is a restaurant app built using Django, designed to manage reservations, orders, and customer interactions for a restaurant. This app provides a seamless experience for both customers and staff, allowing for efficient management of restaurant operations.

## Features

- **Reservation System**: Customers can book tables online, and staff can manage reservations.
- **Menu Management**: Easily add, update, or remove menu items.
- **Order Processing**: Handle customer orders efficiently with real-time updates.
- **User Authentication**: Secure login and registration for customers and staff.
- **Admin Dashboard**: Comprehensive dashboard for managing restaurant operations.

## Technologies Used

- **Django**: A high-level Python web framework that encourages rapid development.
- **HTML/CSS**: For structuring and styling the web application.
- **JavaScript**: For adding interactivity to the frontend.
- **SQLite**: A powerful, open-source object-relational database system.
- **Bootstrap**: For responsive and modern UI design.
